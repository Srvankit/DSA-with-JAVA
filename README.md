## 📈 Problem-Solving Approach

For every problem, the focus is on understanding:

```text
1. Problem
      ↓
2. Brute Force Approach
      ↓
3. Identify Pattern
      ↓
4. Optimize
      ↓
5. Implement in Java
      ↓
6. Analyze Complexity
      ↓
7. Test Edge Cases
```

The objective is to understand **why a solution works**, not simply memorize the code.

## ⏱️ Complexity Analysis

I am actively focusing on understanding algorithmic complexity.

Common complexity levels:

```text
O(1)        Constant
O(log n)    Logarithmic
O(n)        Linear
O(n log n)  Linearithmic
O(n²)       Quadratic
O(2ⁿ)       Exponential

```
